# OpenCells Dike

## Descripción

Proyecto de aprendizaje para construir una plantilla de interfaz CRM/SaaS
con OpenCells y Web Components, tomando Able Pro como referencia visual.

## Estado actual

En desarrollo. El repositorio cuenta con la configuración inicial de Git
y las reglas de exclusión. La aplicación con OpenCells todavía no está implementada.

## Entorno de desarrollo

Herramientas disponibles al iniciar el proyecto; no representan requisitos mínimos.

- macOS y terminal Warp.
- Node.js: 22.17.1.
- npm: 10.9.2.
- pnpm: 11.10.0.
- Git: 2.50.1.
